# Security Policy

## Supported versions

No public release is supported during Phase 0. No production deployment should rely on this scaffold.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** / private vulnerability reporting channel for this
repository once enabled in repository Settings > Security. Do **not** open public issues containing
exploit details, private evidence, credentials, or undisclosed vulnerabilities.

If private reporting has not yet been enabled, contact Vera Anchor through an existing verified
organizational channel; no unaudited security email address is asserted here.

The project will document response times and supported release windows before v1.0.0.
